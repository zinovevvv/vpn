## Установка

1. Открой эту страницу на устройстве, где установлен HAPP.
2. Добавь routing rules в HAPP по инструкции для твоей версии клиента.
3. Если HAPP просит ссылку на конфиг или файл, используй публичные routing-only файлы из README.
4. После добавления правил переподключи VPN, чтобы роутинг применился.

Инструкция не содержит приватных ключей или персональных VPN-профилей.
