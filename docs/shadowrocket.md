# Shadowrocket

Публичный конфиг:

<https://raw.githubusercontent.com/zinovevvv/vpn/main/configs/shadowrocket/neplach-routing.conf>

## Установка

1. Скопируй ссылку выше.
2. Открой Shadowrocket.
3. Перейди в `Config`.
4. Нажми `+`.
5. Выбери импорт/загрузку из URL.
6. Вставь ссылку и скачай конфиг.

## Что делает конфиг

- локальные сети идут напрямую;
- `.ru`, `.su`, `.рф` и российский `GEOIP` идут напрямую;
- банки, маркетплейсы, VK, Avito и похожие сервисы идут напрямую;
- Telegram, torrent-трекеры и часть заблокированных/независимых медиа идут через `PROXY`;
- все остальное идет через `PROXY`.

Конфиг не содержит серверов и ключей. Он рассчитан на клиента, где уже есть
рабочий proxy / subscription.
