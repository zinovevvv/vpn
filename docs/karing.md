## Установка

1. Скопируй raw-ссылку выше или скачай JSON.
2. Открой Karing.
3. Открой `Settings` -> `Diversion` -> `Diversion rules`.
4. Добавь raw-ссылку как remote rule set или импортируй скачанный JSON в custom rules.
5. Переподключи VPN, чтобы правила применились.

Конфиг содержит только правила роутинга и не содержит приватных ключей.
