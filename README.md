## Настройка подписки и выбор сервера

Эти шаги нужны и на телефоне, и на компьютере. Выполни настройку один раз, сразу после добавления подписки.

1. Открой настройки нужной подписки:

   - **В новых версиях:** на главном экране нажми три точки `⋯` рядом с подпиской → `Settings`.
   - **В старых версиях:** нажми шестерёнку на главном экране → открой раздел подписок → настройки нужной подписки.
2. Включи все три пункта:

   | Пункт | Что он делает |
   | --- | --- |
   | `Update on open` | Обновляет список серверов при открытии приложения. |
   | `Ping on open` | Автоматически проверяет время отклика серверов при открытии. |
   | `Sort by ping` | Сортирует серверы по времени отклика: с меньшим временем — выше. |

3. Вернись на главный экран и дождись завершения проверки пинга. Если проверка не началась, нажми **значок спидометра**.
4. Выбери сервер с **самым маленьким числом в мс** — это его время отклика (пинг). Например, из `80 мс` и `250 мс` выбери `80 мс`. Ориентируйся на это число, а не на страну.
5. Включи VPN и проверь, открывается ли нужный сайт или приложение.

**`n/a` означает, что результата проверки нет.** Дождись завершения проверки или запусти её ещё раз. Для подключения выбирай сервер, у которого показано число в мс. Низкий пинг помогает выбрать сервер, но если нужный сайт не открывается, попробуй следующий по списку.

## Если VPN не работает

1. Отключи VPN и проверь, работает ли интернет без него. Если нет — восстанови Wi-Fi или мобильный интернет.
2. Нажми **круговые стрелки** рядом с подпиской и дождись обновления — это загрузит актуальный список серверов.
3. Нажми **спидометр** и дождись завершения проверки — это покажет время отклика серверов из списка.
4. Выбери другой сервер с минимальным числом в мс, включи VPN и проверь нужный сайт или приложение. Если он не работает, попробуй следующий сервер с числом в мс.

**Круговые стрелки обновляют подписку, спидометр проверяет пинг.** Обновление списка само по себе не показывает, какие серверы отвечают сейчас. Если после повторной проверки у всех серверов остаётся `n/a` или ни один не подключается, обратись к администратору.
