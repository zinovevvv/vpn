# Neplach VPN

Скопируй ссылку подписки, которую выдал администратор, и выбери своё устройство.

## HAPP на телефоне

| iPhone / iPad | Android |
| --- | --- |
| [**Установить из App Store**](https://apps.apple.com/ru/app/happ-proxy-utility-plus/id6746188973) · [Global](https://apps.apple.com/us/app/happ-proxy-utility/id6504287215) | [**Установить из Google Play**](https://play.google.com/store/apps/details?id=com.happproxy) · [APK](https://github.com/Happ-proxy/happ-android/releases/latest/download/Happ.apk) |

Открой HAPP → `+` → добавь ссылку подписки из буфера, по QR-коду или deeplink → подключись.

## HAPP на компьютере

| Windows | Mac |
| --- | --- |
| [**Скачать HAPP для Windows**](https://github.com/Happ-proxy/happ-desktop/releases/latest/download/setup-Happ.x64.exe) | [**Скачать HAPP для macOS**](https://github.com/Happ-proxy/happ-desktop/releases/latest/download/Happ.macOS.universal.dmg) |

Добавь ссылку подписки в HAPP и подключись. Чтобы сайты ходили напрямую или через VPN по правилам, нажми кнопку:

### [**Настроить роутинг сайтов в HAPP →**](https://raw.githack.com/zinovevvv/vpn/main/happ-routing.html?v=261011)

Инструкция подскажет, как импортировать профиль и назначить его подписке. Если в HAPP написано, что роутинг недоступен для JSON-подписки, нужен обычный профиль подписки.
